Welcome to the Point of Interest broker, a tool for exploring ZTF/LSST alerts and creating custom watchlists.
This broker is designed to help astronomers quickly sift through the vast amount of data generated by these surveys and identify objects of interest.

Quick Usage Guide: The table below lists alerts ordered by date, newest first. Use the arrows in the table headers to sort and the input fields to filter the data.
Click any object_id to view the object's details. To see an object's alert history, filter by its object ID.
Sign up for an account to create custom watchlists and save favorite alerts. For a full breakdown of table filters and features, or to learn more about the broker, check out the Help page.
